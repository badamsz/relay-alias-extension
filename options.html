Relay Aliases — Settings

This extension talks directly to relay.firefox.com using your account's API key. The key is stored only in this browser (chrome.storage.local) and is never sent anywhere except Mozilla's Relay API.

  1. Sign in at relay.firefox.com.
  2. Click your profile icon (top right) → Settings.
  3. Copy the value shown under API key.
  4. Paste it below and click Save.

Right-click any text field on a page and choose “Insert a new Relay email mask here” to generate and fill in a mask without opening the popup.
